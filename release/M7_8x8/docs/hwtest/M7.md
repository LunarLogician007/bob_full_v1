# M7 hardware test: the heterogeneous fabric generated from VPR's rr graph

Build: `hw/build.cfg` has `tag = M7`, `top = bob_top`, `idcode = 9BEEF093`, `usercode = 00000007`.

This is the complete FPGA with its routing generated from VPR's routing-resource graph (OpenFPGA's method):
- a 10 × 10 VPR grid: an 8 × 8 core inside an I/O ring
- 48 CLBs (LUT6 + FF + carry), 2 BRAMs (column x=3) and 2 DSP slices (column x=6)
- 32 I/O pads, L4 unidirectional routing at W=24 with a Wilton switch block
- a 9400-bit chain and a 64-cell boundary

SW0/SW1/BTN0..3 sit on West-edge pads, LD0..LD2 on East-edge pads, and LD3 is still DONE. The old `fpga4x4_top` sources are frozen in `release/hw_M6/`.

1. Replace `E:\bob_full_v1\hw` and run `build.tcl`. The top changed, so it rebuilds, and the source list sync removes the retired 4×4 files from the project.
   - Expect a longer synthesis than M6: ~2200 routing muxes plus a 9400-bit shift/shadow chain.
   - Expect combinational-loop warnings (Synth 8-295). LUTLP-1 is downgraded for `bob_top` in `drc_waiver.tcl`.
2. Program the board, copy `bob_vivado\out\M7\` to `docs/reports/M7/`, then run `make check`. The report checks still require TCK constrained, RAMB18 ≥ 1 and DSPs ≥ 1 (expect 2 RAMB18 and 2 DSP48E1).
3. `timing.rpt`: WNS ≥ 0 on sysclk. If it is negative, send `timing.rpt`. The multicycle exceptions now match `*u_clb_*/q_reg`, `*u_bram*/u_core/*` and `*u_dsp*/u_core/*`; there must be no "No valid object" warnings for them.

## Automatic (`make hwtest M=M7`)

The regression runs first: `idcode` (`0x9BEEF093`), `bypass`, and `selftest` (all 12 designs, now routed across the grid, including `cross`).

Then every earlier check runs again on the new fabric:
- config plane: usercode (7), chain-length (9400), ir-status, crc-reject-live, gts, gsr-gwe, capture-user1, jprogram, showcase-live
- CLB and user clock: ce-sr, counter-step, counter-run
- BRAM: bram-init, bram-locked, bram-rom, bram-modes
- DSP: dsp-modes, dsp-mult, dsp-accum

Then M7:

| check | pass means |
|---|---|
| bram-select | both BRAMs behind one USER4 register: 16 words written to each read back from their own BRAM; SELECT 9 is ignored |
| pipeline | pad → LUT → FF → BRAM → DSP → pad. INTEST SW1..0 goes through two CLB flip-flops to bram1's address; bram1's DOA[2:0] feeds dsp0 A; B = 3 comes from const-1 pins; PREG. LD2..0 = (mem × 3)[2:0] for 8 vectors |
| counter8 | an 8-bit JTAG-stepped counter up the whole of column 8 (seven carry directs) steps n+5 per n-bit CAPTURE scan, through 255 → 0 |
| pipeline-live | leaves the pipeline on the real switches, contents 3, 6, 4, 5 |
