Every tile owns one word of every frame

This is the layout planned for M21a, drawn for grid column x = 1 (FAR column 2) with bob's real tile sizes. As in 7-series, a frame runs the whole height of a column. Word y of every frame belongs to tile row y, and minor k is the same 32-bit slice of every tile. The current layout is shown in frame_config.html.

    How it maps, for M21a

    • Frames per column = ceil(largest tile ÷ 32): CLB columns 5–6, the BRAM column 4, the DSP column 5, I/O columns 1, and the control column 1 (ctrl's 40 bits in words 0–1).
    • The same minor means the same thing in every CLB column: minors 0–1 are INIT[31:0] and INIT[63:32], minor 2 holds the 7 flags and the first selects, minors 2–5 are routing. AMD keeps LUT contents in fixed minors of a CLB column for the same reason.
    • No field crosses a word. bitgen pads a mux select to the next word rather than split it.
    • FAR does not change (column [16:7], minor [6:0]). The row field [21:17] can later split a column into two 6-tile "clock regions" to get smaller partial-reconfiguration regions, as 7-series does.
    • In the Zynq: buffer word lane y is wired only to row-y tiles, and readback becomes 12 row-local 32-bit lanes rather than one 256:1 × 128 mux.
