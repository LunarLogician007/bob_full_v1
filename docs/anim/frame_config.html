One frame, TDI to tiles, at bob's real size

This shows exactly what bob load does to one frame of the current device. The frame is minor 1 of grid column x = 1 (FAR column 2). Its 128 bits end tile x1y1 and begin tile x1y2. Every number comes from software/bob/device.json.

    The words, in bob's terms

    frame
    The unit of writing: 128 bits, sent as 4 × 32-bit FDRI words. bob has 145 of them, and the whole configuration memory is those frames end to end.
    column
    FAR[16:7], the "major" address. Column 0 is the control tile. Column c holds VPR grid column x = c − 1, with its tiles stacked bottom to top.
    minor
    FAR[6:0]: which frame within that column. Grid column 1 is 1664 bits long, so it takes 13 frames: minors 0 to 12. It is just a counter, not a physical line.
    frame index
    Where the frame sits in the whole memory: base[column] + minor. Column 2 starts at frame 3, so minor 1 is frame 4 = cfg[512 … 639].
    frame buffer
    fbuf (words 0–2) and the word register w in cfg_frames. The 4th word loads all 128 bits into buf_q in cfg_store.
    write enable
    One per frame: we[f] = frame_we && frame_idx == f. On the falling TCK edge, the 128 flip-flops of frame f copy buf_q.

    What the animation shows

    • Frames cut the column every 128 bits, regardless of where tiles begin. A CLB tile is 151–161 bits, so a frame usually carries the end of one tile and the start of the next.
    • One tile can live in two frames. Tile x1y1's muxes are split across minors 0 and 1; one select (CHANX 4350) even has its two bits in different frames. Tile x1y2's flags are split across minors 1 and 2.
    • Partial reconfiguration writes whole frames. Changing only x1y2's LUT rewrites minor 1, which also rewrites x1y1's muxes (with their current values).
    • Readback goes through a 256 : 1 × 128 multiplexer over the whole memory, about 11 800 LUTs.
    • In silicon it looks different. SRAM cells sit in the tiles, bit lines and word lines do the writing and reading, and each tile owns a fixed slice of every frame. This is the layout M21 could move toward.
