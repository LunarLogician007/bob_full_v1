# M7 hardware test: the fabric generated from VPR's rr graph (16-CLB board build)

Build: `hw/build.cfg` has `tag = M7`, `top = bob_top`, `idcode = ABEEF093`, `usercode = 00000007`, `synth_directive = RuntimeOptimized`.

This is the complete FPGA with its routing generated from VPR's routing-resource graph (OpenFPGA's method), at the small profile (`software/bob/device.py` `ARCH_6X4`):
- an 8 × 6 VPR grid: a 6 × 4 core inside an I/O ring
- 16 CLBs (LUT6 + FF + carry) in columns x = 1, 2, 4, 5
- 2 BRAMs (column x = 3) and 2 DSP slices (column x = 6), each 2 rows tall; the DSP cascade and BRAM SELECT are kept
- 20 I/O pads, L4 unidirectional routing at W = 24 with a Wilton switch block
- a 4216-bit chain (M6: 3720) and a 40-cell boundary

Board pins:
- SW0, SW1, BTN0, BTN1 sit on West-edge pads 6, 8, 10, 12.
- BTN2 and BTN3 sit on South-edge pads 0 and 1.
- LD0..LD2 sit on East-edge pads 7, 9, 11.
- LD3 is DONE.

The 8 × 8 profile (48 CLBs, IDCODE `9BEEF093`) is frozen in `release/M7_8x8/` for a build on a faster machine. The old `fpga4x4_top` is in `release/hw_M6/`.

1. Replace `E:\bob_full_v1\hw` and run `build.tcl`. The top changed, so it rebuilds, and the source-list sync removes the retired 4×4 files from the project.
   - Synthesis should take about as long as M6 did (similar chain size, `RuntimeOptimized`).
   - Expect combinational-loop warnings (Synth 8-295); LUTLP-1 is downgraded for `bob_top` in `drc_waiver.tcl`.
2. Program the board and copy `bob_vivado\out\M7\` to `docs/reports/M7/`. Then run `make check`, which requires TCK constrained, RAMB18 ≥ 1 and DSPs ≥ 1. Expect 2 RAMB18 and 2 DSP48E1.
3. `timing.rpt`: WNS ≥ 0 on sysclk, or send `timing.rpt`. There must be no "No valid object" warnings for the `*u_clb_*/q_reg`, `*u_bram*/u_core/*` and `*u_dsp*/u_core/*` multicycles.

## Automatic (`make hwtest M=M7`)

The regression runs first: `idcode` (`0xABEEF093`), `bypass`, and `selftest` (all 12 designs routed across the grid, including `cross`).

Then every earlier check runs again on the new fabric:
- config plane: usercode (7), chain-length (4216), ir-status, crc-reject-live, gts, gsr-gwe, capture-user1, jprogram, showcase-live
- CLB and user clock: ce-sr, counter-step, counter-run
- BRAM: bram-init, bram-locked, bram-rom, bram-modes
- DSP: dsp-modes, dsp-mult, dsp-accum

Then M7:

| check | pass means |
|---|---|
| bram-select | two BRAMs behind one USER4 register: 16 words written to each read back from their own BRAM; SELECT 9 is ignored |
| pipeline | pad → LUT → FF → BRAM → DSP → pad: INTEST SW1..0 passes two CLB flip-flops into bram1's address; DOA[2:0] feeds dsp0 A; B = 3 from const-1 pins; PREG. LD2..0 = (mem × 3)[2:0] for 8 vectors |
| counter8 | a 4-bit JTAG-stepped counter up the whole last CLB column (every carry direct in it) steps (n+5) mod 16 per n-bit CAPTURE scan |
| pipeline-live | leaves the pipeline on the real switches, contents 3, 6, 4, 5 |

After M7 passes, run `make hwtest M=M8` with the same bitstream still loaded (docs/hwtest/M8.md): yosys-synthesised examples, no rebuild.
