# M8 hardware test: yosys-synthesised designs on the M7 fabric

No RTL change and **no Vivado rebuild**: the M7 bitstream (`bob_top`, IDCODE `0xABEEF093`) stays in the PL. `hw/build.cfg` stays tagged M7; `hwtest` prints a note about that.

What M8 adds is the guest flow up to placement, for every design in `work/examples/`:
1. Synthesis: `software/bob/synth.py` runs yosys on bob's cell library (`$lut`, `BOB_FDRE`/`BOB_FDSE`, `BOB_ADD`, `BOB_BRAM18`, `BOB_DSP`).
2. Equivalence: `software/bob/equiv.py` checks the netlist against the source in iverilog.
3. Placement: `software/bob/place.py` packs, places and routes on the fabric.
4. Board comparison: `software/host/hwtest.py` compares the board with the source Verilog.

## Before

- M7 has passed (`make hwtest M=M7`) and its bitstream is programmed.
- `make check` is green on the Mac, which includes `sim/run_synth_sim.sh`: the same placed designs on the complete FPGA RTL.

## Automatic (`make hwtest M=M8`)

The regression runs first: `idcode` (`0xABEEF093`), `bypass`, `selftest`, then `chain-length` (4216).

Each `synth-*` check:
1. rebuilds the design from its Verilog
2. loads the chain
3. writes any BRAM contents over USER4 before startup
4. runs JSTART
5. clocks the fabric once per INTEST scan (USER1 autostep), for 64 clocks
6. requires the LEDs after every clock to equal the source Verilog's output under the same inputs

| check | example | cells |
|---|---|---|
| synth-gates | `work/examples/gates/gates.v`: AND, 6-input parity, mux | 3 `$lut` |
| synth-adder | `work/examples/adder/adder.v`: `sw + btn[1:0]` | 3 `BOB_ADD` (carry chain) |
| synth-counter | `work/examples/counter/counter.v`: 6-bit, enable BTN0, sync reset BTN1 | 6 `BOB_ADD` + 6 `BOB_FDRE` (CE/R on the FF pins) |
| synth-blinky | `work/examples/blinky/blinky.v`: 8-bit free counter | 8 `BOB_ADD` + 8 `BOB_FDRE`; the chain crosses columns |
| synth-ram | `work/examples/ram/ram.v`: inferred block RAM | 1 `BOB_BRAM18`, initial contents over USER4 |
| synth-mult | `work/examples/mult/mult.v`: registered 8 × 6 multiplier | 1 `BOB_DSP` + 7 `BOB_FDRE` |
