# M1 hardware test: `device.py` as the single source of truth

No RTL change, so there's no Vivado run: the M0 bitstream (`0x3BEEF093`) stays on the board. What changed is the host side. `software/host/bitstream.py` now takes every constant, field offset and pad position from `software/bob/device.json`, so the test is whether the board still agrees with it.

On the Vivado machine, copy `bob_full_v1` over the old copy and run `build.tcl` once (plain Run Tcl Script). The fingerprint is unchanged, so it should print **"skipping synthesis and implementation"**. That's the reuse check. It still writes `out/M1/` with the same bitstream and reports. Then program: `set bob_args {program}` followed by `source .../hw/scripts/build.tcl`.

## Automatic (`make hwtest M=M1`)

| check | pass means |
|---|---|
| idcode | `0x3BEEF093` |
| bypass | 1 bit |
| selftest | all 11 designs, now built from `device.json`, match the model through INTEST |
| showcase-live | real LEDs match the model for the current switches |
| chain-length | a 16-bit marker comes out exactly `device.json` width (2896) bits later; readback and the design are unchanged afterwards |
