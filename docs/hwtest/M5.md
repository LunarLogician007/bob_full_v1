# M5 hardware test: complete FPGA + BRAM tile

Build: `hw/build.cfg` has `tag = M5`, `top = fpga4x4_top`, `idcode = 7BEEF093`, `usercode = 00000005`. This is the complete FPGA: M4 plus a **BRAM tile** on the fabric's East edge, one RAMB18-backed 1024 × 18 true-dual-port memory (UG473). The chain is now 3488 bits.

1. Replace `E:\bob_full_v1\hw` and run `build.tcl`. New sources, so it rebuilds.
2. Program the board, copy `bob_vivado\out\M5\` to `docs/reports/M5/`, then run `make check`. **The report checks now require `util.rpt` to show a RAMB18**; LUT-based RAM would fail.
3. `timing.rpt`: WNS ≥ 0, and no "No valid object" warnings for the `u_bram/u_core` multicycle exceptions.

LEDs: LD2..LD0 = `pad_o`, LD3 = DONE.

## Automatic (`make hwtest M=M5`)

Regression first: `idcode` (`0x7BEEF093`), `bypass`, `selftest` (11 designs).

Then the M3 and M4 checks:
- usercode (5), chain-length (3488)
- ir-status, crc-reject-live, gts, gsr-gwe, capture-user1, jprogram, showcase-live
- ce-sr, counter-step, counter-run

Then M5:

| check | pass means |
|---|---|
| bram-init | `d_bram_rom` committed but not started; 64 random words written over USER4 read back exactly |
| bram-locked | after JSTART a USER4 WRITE is refused (`err` = 1, `gwe` = 1) |
| bram-rom | BRAM as a ROM through the fabric: INTEST SW1..0 = 0..3 gives LD2..0 = the low 3 bits of the words written |
| bram-modes | 3 configurations (WRITE_FIRST/READ_FIRST, NO_CHANGE + DOA_REG/WRITE_FIRST, READ_FIRST/NO_CHANGE + DOB_REG): 24 random two-port operations each, pins driven over USER4, one BRAM clock per USER1 step; DO_A and DO_B match `model.py` after every step |
| bram-rom-live | reloads the ROM with contents 001, 010, 100, 111 and leaves it running |

## By hand (`--manual`)

- [ ] After `make hwtest M=M5`: SW1..0 = 00 → LD0, 01 → LD1, 10 → LD2, 11 → LD0+LD1+LD2 (LD3 on throughout)
- [ ] `util.rpt` shows `RAMB18 | 1` (or 0.5 RAMB36 tile) and the LUT/FF numbers are noted next to M4's
- [ ] Optional, on the Vivado machine: `set bob_args {sim sim_top=tb_bram}` then `source .../build.tcl` runs the BRAM model check in XSim too
