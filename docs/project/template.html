An FPGA built inside an FPGA

bob is a complete programmable FPGA written in Verilog. It runs in the programmable logic of a PYNQ-Z2 (Zynq XC7Z020), with its own logic cells, BRAMs, DSP slices, routing, JTAG configuration controller and tool chain. A Mac configures it over JTAG through a Raspberry Pi Pico. ./bob build design.v and ./bob load design.bit take a design from Verilog to the board's LEDs, checked at every step against its source, a golden netlist and a cycle model.
