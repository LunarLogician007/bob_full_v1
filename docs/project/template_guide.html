bob, explained

bob is an FPGA built inside an FPGA: its own logic cells, memories, DSP slices, routing, configuration controller and tool chain, running in the programmable logic of a PYNQ-Z2. This page explains every part — what it is, why it is built that way, how to use it and how to tweak it — and compares it honestly with OpenFPGA, Aegis and the other projects it borrows from.
