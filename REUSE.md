# REUSE — where every file in bob_full_v1 came from

`bob_full_v1/` started as a full copy of `bob/` (hardware-proven: JTAG + 4×4 CLB fabric, 174 simulation checks). `bob/` is frozen as the reference; all development happens here.

Status: **same** = byte-identical to `bob/`, **moved** = same content at a new path, **modified** = changed here (reason given), **new** = written for bob_full_v1.
