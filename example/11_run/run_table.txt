counter loaded on the stand-in board and stepped with INTEST + USER1 autostep: each scan drives
the pins, gives the user clock one edge, and CAPTURE reads every element flip-flop.
Registers are named through capture_map (CAPTURE bit -> the golden netlist's bit).
Stimulus: BTN1 (reset) for 2 clocks, BTN0 (enable) held, released, then reset again.
